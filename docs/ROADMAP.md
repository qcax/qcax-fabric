# Roadmap

- **Local R4.4:** final prepublication architecture and executable staging base.
- **v0.1.0-alpha.1:** public GitHub working plugin-development base: protected clean CI, exact action pins, independent wheels, InstalledImage BootLock, immutable complete release, clean release-asset canary. PyPI is not required for this milestone.
- **PyPI alpha publication gate:** namespace + Trusted Publisher/OIDC + PEP 740 evidence, only after GitHub alpha passes.
- **v0.1.0-alpha.2:** `SANDBOXED_PROCESS` plus at least two real external adapter canaries under held-out conformance.
- **v0.2.0-beta.1:** durable state/migrations, plugin registry/revocation/update semantics and broader platform evidence.
- **v1.0.0:** ABI freeze only after independent external plugins/adapters, compatibility/migration evidence and external security review. No calendar date is asserted.
