# First public alpha clean-slate migration

This clean-slate successor is intended to become the first published QCAX Fabric alpha.

It preserves the admitted public v1alpha1 schema IDs and schema semantics, the eleven distribution
project names, the eight plugin identities/discovery surface, the `qcax.fabric/v1alpha1` plugin ABI,
and the coordinated Python version `0.1.0a1`.

This document does not claim that a GitHub release or PyPI publication already exists. Release
identity remains held until the no-prior-public-artifact/provider check and remaining W8/W9 gates pass.
